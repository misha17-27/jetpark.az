# JetPark.az — PHP-версия с админ-панелью

Сайт jetpark.az, перенесённый с WordPress + Elementor на чистый PHP (без базы данных и без фреймворков),
и панель управления в стиле alizadehgroup.net (`/admin/`).
Дизайн, тексты, картинки и адреса страниц — как на старом сайте.

## Админ-панель — `https://jetpark.az/admin/`

**Первый вход.** Пока не создан ни один пользователь, `/admin/` показывает экран «İlk quraşdırma» — там вы
создаёте первого администратора (имя, e-mail, пароль от 8 символов). Сделайте это **сразу после загрузки
сайта на хостинг**, пока этого не сделал кто-то другой.

Разделы (интерфейс на азербайджанском и русском, переключатель AZ/RU):

| Раздел | Что редактируется |
|---|---|
| İdarə paneli | счётчики заявок (новые / за месяц / всего), статьи, вопросы FAQ, последние заявки, разбивка по типу, состояние сервера |
| Müraciətlər | заявки с сайта: фильтр по статусу и типу, поиск, статусы «Yeni / Baxılır / Tamamlandı», заметки, звонок/WhatsApp в один клик, экспорт CSV |
| Bloq | статьи: заголовок, адрес (slug, создаётся сам из заголовка), визуальный редактор текста, главное фото (уменьшенная копия для карточки делается автоматически), дата, черновик/публикация, SEO-заголовок и описание с превью как в Google (пустой SEO-заголовок → «Заголовок статьи - JetPark»); в списке — точка состояния SEO |
| FAQ | вопросы и ответы, порядок стрелками; на главной показываются первые N (N задаётся в «Mətnlər») |
| Üstünlüklər | карточки «Üstünlüklərimiz» на главной и в «Haqqımızda»: иконка (из набора или своя PNG/WebP), заголовок, текст, порядок |
| Haqqımızda | блок «О нас»: фраза, два пункта, картинка, кнопка |
| Sahibkarlar / Sürücülər | вступительный текст и фото, карточки «Nə təklif edirik?», примечание, фото рядом с формой |
| Mətnlər | первый экран главной, блоки преимуществ и FAQ, тексты формы заявки, страница контактов, подвал |
| Səhifələr | список страниц: адрес, заполнен ли текст, состояние SEO (зелёный — в порядке, жёлтый — title длиннее 60 или description длиннее 160 символов). Для каждой страницы: заголовок и фон шапки, `<title>`, description (с превью как в Google), картинка для соцсетей |
| Parametrlər | телефон, WhatsApp, e-mail, адреса, карта, соцсети, куда слать заявки, Cloudflare Turnstile — **только администратор** |
| İstifadəçilər | пользователи и роли — **только администратор** |
| Profil | своё имя, e-mail, пароль |

В текстовых полях `**слово**` выделяет слово зелёным цветом, как на сайте.

**Роли.** *Administrator* — всё. *Redaktor* — контент и заявки, без настроек и пользователей.

**Безопасность:** пароли хранятся в виде bcrypt-хешей; CSRF-защита всех форм; блокировка входа на 15 минут
после 5 неверных паролей с одного IP; автовыход через 4 часа бездействия; при смене пароля остальные сессии
завершаются; HTML из редактора очищается (скрипты, обработчики событий и `javascript:`-ссылки удаляются);
загрузка только JPG/PNG/WebP до 5 МБ, в `assets/uploads/` выполнение скриптов запрещено.
По желанию — Cloudflare Turnstile на странице входа (ключи в «Parametrlər»).

## Где хранятся данные

Всё, что меняется через панель, лежит в `storage/data/*.json` (база данных не нужна):
`posts`, `faq`, `advantages`, `content`, `seo`, `settings`, `applications`, `users`.
Пока файла нет, используется исходный контент из `data/*.php`. Загруженные картинки — в `assets/uploads/`.

**Резервная копия** = скачать папки `storage/data/` и `assets/uploads/`.

**Обновление уже сохранённых данных.** Если в новой версии меняется исходный контент (например, SEO-тексты),
а на сервере эти данные уже сохранены через админку, нужное обновление описывается в `includes/migrations.php`.
Оно выполняется один раз при первом запросе после деплоя и меняет только то, что не правили вручную.
Выполненные обновления записываются в `storage/data/migrations.json`.

## Заявки с формы

Кнопка «Göndər» сразу открывает WhatsApp на номер из «Parametrlər» с готовым сообщением от имени посетителя:
имя, телефон, тип (Sahibkar / Sürücü). Шаблон сообщения — функция `whatsapp_application_url()` в `includes/functions.php`.

Одновременно (в фоне) `send.php` сохраняет заявку в «Müraciətlər» и отправляет письмо через PHP `mail()`
на адрес из «Parametrlər». Так контакт не потеряется, даже если посетитель не нажмёт «Отправить» в WhatsApp.
`send.php` проверяет поля, CSRF-токен, поле-ловушку для ботов и ограничение «1 заявка в 30 секунд».
Без JavaScript форма отправляется обычным способом и после сохранения переводит на WhatsApp.

## Локальный запуск

```bash
php -S localhost:8000 index.php
```

Сайт: http://localhost:8000/, панель: http://localhost:8000/admin/

## Установка на хостинг (cPanel + GitHub)

Код хранится в https://github.com/misha17-27/jetpark.az. Кнопка «Deploy HEAD Commit» в cPanel запускает
`.cpanel.yml` → `deploy.sh`, который копирует файлы в `/home/jetpark/public_html/`:

- на сервере ничего не удаляется;
- служебные файлы (`.git`, `deploy.sh`, `README.md`…) на сайт не попадают;
- блок с версией PHP, который cPanel пишет в `.htaccess`, сохраняется.

Данные админки (`storage/data/`, `assets/uploads/`) в git не хранятся, поэтому обновления их не затрагивают.

Требования: PHP 8.0+ (на сервере сейчас 8.4) с расширениями `mbstring` и `dom`, для уменьшения фото — `gd`;
Apache или LiteSpeed с `mod_rewrite`.

**Первая установка**

1. Резервная копия WordPress:
   - файлы: File Manager → `public_html` → Compress, скачайте архив;
   - база данных: phpMyAdmin → Export.
2. Уберите WordPress из `public_html`, иначе старые `wp-admin` и `wp-login.php` останутся доступны:
   - File Manager → Settings → включите «Show Hidden Files»;
   - выделите всё, **кроме** `.htaccess`, `.well-known` и `cgi-bin`;
   - Move → `/wp-backup`.
3. Git™ Version Control → Create:
   - Clone URL — `https://github.com/misha17-27/jetpark.az.git`;
   - Repository Path — `repositories/jetpark.az`;
   - нажмите Create.
4. Manage → вкладка «Pull or Deploy» → **Deploy HEAD Commit**.
5. Сразу откройте `https://jetpark.az/admin/` и создайте администратора.
6. В «Parametrlər» проверьте e-mail для заявок, отправьте тестовую заявку с сайта.

**Обновление сайта вручную:**

1. Отправьте изменения (push) в GitHub.
2. Git™ Version Control → Manage → Pull or Deploy.
3. Нажмите «Update from Remote», затем «Deploy HEAD Commit».

**Автоматическое обновление.** `autodeploy.sh` раз в 5 минут проверяет GitHub. Если в `main` появился новый коммит,
скрипт забирает его и выкладывает на сайт тем же `deploy.sh`. Когда новых коммитов нет, он ничего не делает
и ничего не пишет, поэтому cron не шлёт писем. Неудачный деплой повторяется при следующем запуске.
Журнал — файл `jetpark-deploy.log` в домашней папке (File Manager → Home).

Настройка (один раз):

1. Обновите сайт вручную, как описано выше, чтобы `autodeploy.sh` попал на сервер.
2. cPanel → Cron Jobs → Add New Cron Job:
   - Common Settings — «Once Per Five Minutes (*/5 * * * *)»;
   - Command — `/bin/bash /home/jetpark/repositories/jetpark.az/autodeploy.sh`;
   - нажмите «Add New Cron Job».

Всё, что попадает в `main` на GitHub, через несколько минут оказывается на сайте. Поэтому включите в GitHub
двухфакторную защиту (Settings → Password and authentication).

Если сайт открывается не из `public_html` (например, это дополнительный домен), поменяйте путь в `.cpanel.yml`
(его используют и ручной, и автоматический деплой).

**Cloudflare.** Сайт работает через Cloudflare:

- с http на https перенаправляет сам Cloudflare;
- с www на адрес без www перенаправляет `.htaccess`;
- реальный IP посетителя (для блокировки входа и в заявках) берётся из заголовка `CF-Connecting-IP`,
  но только если запрос пришёл с адресов Cloudflare.

Для nginx вместо `.htaccess`:

```nginx
location ~ ^/(includes|pages|data|storage)/ { deny all; }
location = /config.php { deny all; }
location ~ ^/assets/uploads/.*\.(php|phtml|phar|html?|svg)$ { deny all; }
location = /admin/ { try_files /admin/index.php =404; }
location / { try_files $uri /index.php?$query_string; }
```

  в невидимом блоке (смещён за экран на -7566px). Такие вставки обычно появляются после взлома WordPress или
  продажи ссылок и вредят SEO. Если вы её не ставили — WordPress стоит проверить на взлом и сменить пароли.
- Кнопки «Daha çox» в FAQ, которые вели на `#` (никуда), убраны.
- Google reCAPTCHA заменена на скрытое поле-ловушку + проверку времени заполнения (не нужен ключ Google).
- На странице «Əlaqə» справа от формы добавлена карта Google (отключается в «Mətnlər»).
- Добавлены meta-описания, Open Graph, `sitemap.xml`, разметка Schema.org для FAQ и статей, `lang="az"`.
- Мобильная версия сверстана заново (меню выезжает справа).
